# 贾府多重身份关系图谱

《红楼梦》贾府 30 人、97 条关系，按五层身份分开堆放的三维交互图。

- **L0 血缘**：父子 · 母女 · 兄妹 · 族亲
- **L1 婚姻姻亲**：夫妻 · 婆媳 · 翁婿 · 姨甥
- **L2 制度授予**：君臣 · 主仆 · 师生 · 奴籍
- **L3 党援庇护**：门生 · 心腹 · 依附 · 勾结
- **L4 实践互动**：知己 · 敌对 · 争权 · 争宠

拖动旋转，滚轮缩放，点击左侧层名可把该层调暗，悬停某人可看其全部身份。
图中金色 ⇅ 标出三处「方向反转」——元春与贾母、贾政、王夫人，
